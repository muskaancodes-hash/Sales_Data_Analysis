# Sales_Data_Analysis
Sales data analysis using Python, Pandas, and Matplotlib with data visualization and insights.
# Sales Data Analysis

This project analyzes sales data using Python and Pandas.

## Tools Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Objective

To analyze sales data, calculate total sales, and visualize the results using charts.

## Dataset

Sales data is stored in a CSV file and analyzed using Pandas.
## Part 2: Basic Sales Analysis

Basic sales analysis is performed using Pandas. Summary statistics, total sales, and product-wise sales are calculated using functions such as `describe()`, `sum()`, and `groupby()`.
## Part 3: Sales Visualization

Sales data is visualized using Matplotlib. Charts are used to compare sales performance and identify patterns in the data.
